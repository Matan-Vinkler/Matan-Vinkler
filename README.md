## 👋 About Me

I'm an embedded systems and AI developer focused on **end-to-end intelligent physical systems**: software that perceives the real world, reasons under constraints, and controls hardware reliably.

My background includes approximately **three years of embedded and algorithm development in the Israel Defense Forces**, alongside hands-on projects in robotics, GPU computing, deep learning, and edge deployment. I'm currently pursuing a **B.Sc. in Electrical Engineering at Tel Aviv University**.

I enjoy working across abstraction layers — from microcontroller firmware, sensor interfaces, and real-time software to ROS 2 autonomy stacks, neural networks, and hardware-accelerated inference. I care about the engineering details that determine whether a system actually works: **latency, power, memory, robustness, and hardware–software integration**.

- **Edge AI deployment:** optimizing vision and learning models for resource-constrained compute, including NVIDIA Jetson and Hailo.

## 🧭 How I Approach Engineering

I like to build **working systems, not isolated demos**. My typical workflow connects:

**Problem definition → system architecture → simulation/prototyping → embedded and AI implementation → hardware integration → measurement and iteration.**

I'm especially interested in the boundaries between disciplines: how an AI model meets real-time constraints, how a robot's software architecture affects safety and reliability, and how hardware choices shape the capabilities of an autonomous system.

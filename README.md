## 👋 About Me

I build **intelligent physical systems** at the intersection of embedded hardware, on-device AI, and robotics. My work turns real-world problems into working solutions by combining low-level firmware, electronics, and performance-aware AI, always with real-world constraints (latency, power, memory) in mind.

<table>
  <tr>
    <td width="33%" valign="top">

**🔌 Embedded & Hardware**<br/>
Firmware, PCB design, sensor and actuator integration on microcontrollers and single-board computers.

</td>
    <td width="33%" valign="top">

**🧠 Edge AI & ML**<br/>
Model training, fine-tuning, and deployment on accelerators: from CUDA kernels to Hailo and Jetson.

</td>
    <td width="33%" valign="top">

**🤖 Robotics**<br/>
ROS 2 navigation, SLAM and localization, simulation-to-hardware workflows, autonomous driving.

</td>
  </tr>
</table>

### 🔭 Currently
- Working on edge AI and computer vision on **NVIDIA Jetson Orin Nano Super**
- Object detection with **YOLO**, optimized for deployment with **TensorRT**
- Running **ROS 2** on **JetPack**, containerized with **Docker** for reproducible setups

## 🚀 Featured Projects

| Project | What it does | Stack |
|:--|:--|:--|
| [**bumperbot**](https://github.com/Matan-Vinkler/bumperbot) | Differential-drive mobile robot on ROS 2, running in Gazebo simulation and on a real Raspberry Pi + Arduino build. Maps and localizes with SLAM Toolbox and AMCL. | `C++` `ROS 2` `SLAM` `Gazebo` `Arduino` |
| [**self-driving-robot**](https://github.com/Matan-Vinkler/self-driving-robot) | Autonomous car on Raspberry Pi 5 with the AI Kit (Hailo-8L). Runs a Keras NVIDIA behavioral-cloning model compiled to `.hef`, fed by a Picamera2 preprocessing pipeline. | `Python` `Keras` `Hailo` `Raspberry Pi` |
| [**neural-network-cuda**](https://github.com/Matan-Vinkler/neural-network-cuda) | Lightweight feed-forward neural network built from scratch in C++ and CUDA, with GPU-accelerated linear layers, cuRAND weight initialization, and manual memory management. | `C++` `CUDA` |
| [**phi-3.5-finetuned-medqa**](https://github.com/Matan-Vinkler/phi-3.5-finetuned-medqa) | Fine-tunes Phi-3.5-Mini-Instruct with LoRA into a lightweight, domain-specific medical assistant. | `Python` `LoRA` `LLMs` |
| [**vit-paper-implementation**](https://github.com/Matan-Vinkler/vit-paper-implementation) | From-scratch reimplementation of *"An Image is Worth 16×16 Words"* (Dosovitskiy et al., 2020). | `Python` `PyTorch` `Transformers` |
| [**low-battery-alarm**](https://github.com/Matan-Vinkler/low-battery-alarm) | PCB design that detects low battery voltage with a high-voltage divider and drives a buzzer through a 5 V DC-DC module. Includes input filtering, TVS surge protection, and a transistor driver stage. | `Analog` `PCB` `Power` |
